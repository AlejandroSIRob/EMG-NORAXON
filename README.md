# EMG_NORAVOX Project

Colección de scripts y datos para análisis multimodal de señales EMG e IMU.
Incluye:

- librería `noraxon_analytics.py` y ejemplos (`example_noraxon_analytics.py`)
- herramientas de calibración y procesamiento (`calibration*.py`, `repetidor.py`)
- módulos de sincronización multiplataforma (`SYNC/` y `SYNC-EMG-IMU/`)
- estudios de sinergias (`Synergy-study/`)
- datos de prueba y resultados en carpetas `Data`, `Pruebas`, `Movimientos`, etc.

---
## Notas

- El repositorio está orientado a laboratorio de investigación en biomecánica.
- Los datos internos se guardan en subcarpetas (Pruebas, Movimientos, Calibration).
- Puede agregarse más documentación por submódulo según necesidad.
